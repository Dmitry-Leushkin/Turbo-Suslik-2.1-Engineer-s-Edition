# Processing Emotional States

[Book contents](../README.md) | [Part contents](README.md)

The next core element of Phase 1: working the **emotional scale**. At this stage, you run a list of emotions and emotional states through `Process this`. The list is built on the AGFLAP–CAP scale, originally proposed by Lester Levenson. In the source model, emotions get grouped into nine categories: six maladaptive states (Apathy, Grief, Fear, Lust, Anger, Pride - AGFLAP), and three functional ones (Courage, Acceptance, Peace - CAP).

This book runs an expanded, revised version of that scale - this is the build you'll be processing in Phase 1.

The logic here: each emotion on the list isn't treated as a single atomic value - it's a set of distinct variants and shades. Processing these individually reduces the automaticity of their activation against typical internal or external triggers. In parallel, it weakens the fixed response patterns wired to them, and the subpersonality processes maintaining those reactions. End state isn't emotional suppression - it's more freedom relative to the emotion itself: the ability to experience a state without long fixation, or with minimal residual latency after it fires.

As work continues - not just in Phase 1, ongoing - the tendency to get stuck in a given emotional state usually drops significantly. Where an unpleasant state used to run for hours or days, over time its active runtime shrinks. In some cases you get a fast return to neutral or calm shortly after a spike. This isn't repression, isn't suppression - it's a drop in the emotion's automatic hold on attention. Working the scale is step one toward that.

After clearing a significant chunk of the list, some practitioners land in a state of emotional neutrality: no pronounced negativity, no pronounced euphoria either. Can feel unusual, even unsettling, especially the first time you hit it. Important to be clear: **this isn't a loss of emotional capacity, and it isn't a system failure**. Full capacity to experience any emotion stays intact. What changes is purely the degree of **automaticity** and lack of control around when a given state fires.

Working the scale doesn't guarantee these emotions never show up again. The human emotional range is far wider than any fixed list can cover. So a familiar state reappearing later isn't a rollback signal or a sign the work failed. With practice, though, the automatic version of the reaction gets progressively less sustainable, and that shift is usually clearly visible in direct experience. Clearing the scale isn't the end goal - it's the base layer everything else in emotional work builds on.

Technically, execution is minimal. Start from the bottom of the scale - the heaviest, most inert states first. Pull one emotion or state from the list. Say its name (aloud or silently) while briefly registering the actual felt experience behind it, then issue `Process this`. Loop until a yawn fires, or up to ten repetitions. Then move to the next state, or go back to whatever else you were doing. E.g.: `"Hopelessness - process this."`

At a steady, moderate pace, the full list clears in under a month. Acceptable speed and overprocessing signs get their own coverage in a later chapter ("Work Plan"). What matters to lock in here: working the emotional scale is a **mandatory** part of Phase 1. Not skippable, not shortenable. The entire scale runs to completion, including the states classified as "positive."

Emotion processing can run in parallel with polarity work - these two pipelines don't conflict or block each other. The one constant is individual pace. The goal isn't speed. It's steady, careful throughput without overload.
