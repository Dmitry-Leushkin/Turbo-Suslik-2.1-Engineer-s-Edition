# Turbo-Suslik 2.1: Engineer's Edition

**By Dmitry Leushkin**

Turbo-Suslik is a protocol-based system for working with persistent emotional reactions, beliefs, behavioral patterns, and other mental material.

Instead of trying to replace unwanted thoughts with positive ones, TS uses structured language instructions called protocols to process the material that keeps old reactions active.

The Engineer's Edition presents the system in a more technical language: protocols as instructions, mental material as interconnected networks, and processing as a change in the way those networks influence attention, emotion, bodily reactions, and behavior.

## What is the point?

Many reactions continue long after the situation that created them is gone.

You may understand intellectually that something is no longer relevant and still react to it automatically.

Turbo-Suslik is designed to reduce that automatic control.

The goal is not to install a new belief system. It is to make old material less capable of running the present.

## How does it work?

In simplified terms:

`mental material → protocol → directed internal processing → changed response`

A protocol tells the system what material to work with and defines how that material should be processed.
